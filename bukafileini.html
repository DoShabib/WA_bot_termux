🤖 Panduan Bot WhatsApp habibGM (Mode Sibuk)

Dokumentasi lengkap instalasi modul, daftar perintah, dan konfigurasi owner.

📦 Modul NPM yang Diperlukan

Salin dan jalankan perintah berikut di terminal/panel Anda:

npm install @whiskeysockets/baileys @hapi/boom pino qrcode

Rincian Modul:

  • @whiskeysockets/baileys — Pustaka utama untuk menghubungkan bot ke WhatsApp dan menangani panggilan masuk (call handling).
  • @hapi/boom — Modul untuk menangani objek error dengan format HTTP yang rapi saat koneksi bot terputus atau tersambung kembali.
  • pino — Pustaka logger cepat yang dipakai oleh Baileys (diatur ke mode silent agar terminal Anda tidak terlalu ramai oleh teks log).
  • qrcode — Modul yang digunakan untuk mengonversi dan menyimpan QR Code login secara otomatis menjadi file gambar WhatsApp.png.

⚡ Daftar Perintah Bot habibGM (Mode Sibuk)

Semua perintah di bawah ini hanya bisa diketik oleh Anda (Owner), baik melalui chat pribadi ke nomor bot maupun langsung di ruang obrolan "Kirim pesan ke diri sendiri". Perintah ditulis langsung tanpa menggunakan awalan titik (.).

daftar <nomor>

Fungsi: Mendaftarkan nomor penting (whitelist/VIP) agar bebas menelepon dan mengirim chat ke kamu meskipun bot sedang dalam Mode Sibuk.

Contoh: daftar 085xxxxxxxxx (nomor otomatis diconvert ke format internasional 628...)

sibuk

Fungsi: Mengaktifkan Mode Jangan Ganggu (habibGM) secara total.

Efek: Panggilan dari orang tak terdaftar ditolak otomatis & chat tak dikenal dibalas teks "lagi sibuk jangan ganggu" (hanya 1 kali setiap 15 menit).

normal / online

Fungsi: Mematikan Mode Sibuk dan mengembalikan fungsi WhatsApp ke seperti semula.

Efek: Telepon dan chat masuk kembali normal tanpa penolakan atau balasan otomatis bot.

list

Fungsi: Menampilkan daftar seluruh nomor yang sudah kamu daftarkan ke dalam daftar pengecualian (Whitelist).

hapus <nomor>

Fungsi: Menghapus satu nomor tertentu dari daftar pengecualian.

Contoh: hapus 085xxxxxx

hapus semua

Fungsi: Menghapus seluruh daftar nomor pengecualian sekaligus (nomor Owner kamu sendiri aman dan tidak ikut terhapus).

help

Fungsi: Memunculkan teks panduan menu perintah ringkas di dalam chat.

🛠️ Tutorial Cara Mengedit index.js

Syarat Utama: Harus punya Pterodactyl panel.
  1. Buka file index.js Anda melalui panel Pterodactyl atau editor kode yang biasa Anda gunakan.
  2. Cari baris kode bagian atas yang mendefinisikan variabel ownerNumber (biasanya berada di sekitar baris ke-6 hingga ke-8). Kodenya seperti ini:
    const ownerNumber = '6281xxxxxxxx';
  3. Ganti nomor '6281xxxxxxx' dengan nomor WhatsApp baru yang ingin Anda jadikan Owner.
    ⚠️ Catatan Penting: Pastikan menggunakan format nomor internasional dengan awalan 62 (kode negara Indonesia) dan tanpa menggunakan tanda plus (+), spasi, atau simbol apa pun (contoh: '6281234567890').
  4. Klik tombol SAVE CONTENT di bagian bawah panel.
  5. Pergi ke tab Console, lalu klik tombol Restart agar bot memuat ulang data nomor owner yang baru. Setelah di-restart, nomor baru resmi menjadi Owner.

Simpan dan jadikan panduan cepat kapan pun Anda mengoperasikan bot.
