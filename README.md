Tutorial Cara Menginstalasinya
1. download Termux di fdroid versi terbaru.
2. jika sudah install aplikasi Termux dan masuk ke dalam aplikasinya
3. tunggu sampai setup selesai.

jika sudah kamu ketikkan perintah
```
pkg update && pkg upgrade -y
```
atau copy saja.
dan jika selesai kamu ketikkan perintah
```
pkg install git vim curl micro nodejs npm -y
```
jika ada yang salah hapus npm atau nodejs

dan tunggu hingga selesai.
kemudian jika sudah ter install

kamu masuk folder 
dengan perintah 
```
cd ~/WA_bot_termux
```
lalu kamu ketikkan perintah

```
npm install @whiskeysockets/baileys @hapi/boom pino qrcode
```

jika sudah.
kamu bisa mengeditnya index.js dengan mengganti nomer telpon kamu.
dengan perintah vim atau macro.
contoh atau kamu copy saja

```
macro index.js
```
atau
```
vim index.js
```

selesai dan enjoy
